🔧 COMMON COMMANDS

Start services:
  docker-compose up -d

Check status:
  docker-compose ps

View logs:
  docker-compose logs -f

Stop services:
  docker-compose down

Access MySQL:
  docker exec -it library-mysql mysql -u root -proot librarymanagement

Access Redis:
  docker exec -it library-redis redis-cli -a redis_pass123
